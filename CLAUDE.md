# hzero

- `DESIGN.md` is the design language: fonts, colours, the website grid and the exact chart specification. Follow it for every visual change.
- Charts are made in Jupyter with the `notebooks/hzero_charts` package (see DESIGN.md, part 3). Never style a chart by hand.
- Website: `web/` (Vite + TypeScript). Build with `npm run build` in `web/`.
- No monospace text anywhere.
