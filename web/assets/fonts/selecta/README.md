# Selecta (title font)

Put the Selecta font files here (woff2 preferred; woff/otf/ttf also work). `src/fonts.ts` registers every file in
this folder as the "Selecta" family and reads weight/style from the file name.

Trial files from Maxitype may only be used for testing and pitches, not on the live website
(Maxitype EULA 2.1, section 6). Buy a web licence before deploying to hzero.tech.

Currently in this folder: the "Selecta Trial Unlicensed" files (Thin, Light, Regular, Medium, Bold, Black, each
with italic). When the licence is bought, replace them with the licensed files; the loader needs no change as
long as the file names still contain the weight.
